# TallyShot — Project Overview

## What TallyShot Is
A premium AI-powered consumer intelligence platform
and expense tracker. Users scan any barcode on earth
— food, drink, alcohol, cosmetics, household
products — and get rich AI-powered intelligence
about what they are buying.

## Tech Stack
- React Native + Expo (managed workflow)
- TypeScript, strict mode
- Expo Router (file-based navigation)
- Tested on: Samsung Android via Expo Go
- Target stores: Google Play Store + Apple App Store

## Design Identity
- Dark mode first
- Premium fintech + AI aesthetic
- Primary accent: #00C896 (teal)
- NEVER orange. NEVER cluttered. NEVER generic.
- Spring physics on all transitions
- Skeleton screens — never spinners
- Haptics on meaningful moments only

## Core Features
1. Barcode scanner — any product on earth
2. Receipt scanner — AI reads and logs receipts
3. Expense tracker — spending categories + insights

## Product Identity (non-negotiable)
TallyShot is NOT a basic barcode utility.
TallyShot IS the smartest shopping companion
available on mobile.
